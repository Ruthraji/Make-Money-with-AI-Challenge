# Make Money with AI Challenge - Mini Projects

Documentation and mini-projects completed during the 4-Day Make Money with AI Challenge.

## Projects Overview

* **Day 1: Prompting Mastery** 
  Focuses on structured prompt engineering techniques, contextual framing, and clear outputs.
  
* **Day 2: Vibe Coding Experience** 
  Interactive mini-project built using AI-assisted coding principles and rapid prototyping.
  
* **Day 3: First AI Operating System** 
  Implementation of custom system instructions, structured persona prompts, and AI agent workflows.
  
* **Day 4: Automation System** 
  Built a live automated workflow using **Pabbly Connect** to trigger scheduled Gmail reminders for monthly internet bill payments (Includes workflow diagram & live email output proof).
